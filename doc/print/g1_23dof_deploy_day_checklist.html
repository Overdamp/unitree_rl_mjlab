4. Passive (kp = 0): ตรวจ kd · เวลาเริ่ม

  • T2 = gains match: Passive (kp = 0 ทุก slot, kd 2.5–6)
  • หมุนด้วยมือ ทีละ joint ช้า 2–3 รอบแล้วเร็ว 2–3 รอบ: ขาซ้าย → ขาขวา → waist yaw → แขนซ้าย → แขนขวา
  • หนืดขึ้นเมื่อหมุนเร็ว ไม่ดีดกลับที่เดิม ไม่กระตุก

5. FixStand (gain ของ Unitree): ตรวจ kp · เวลาเริ่ม

  • รีโมต LT + ↑: ทุก joint เข้าท่ายืนใน 3 s ไม่มีตัวไหนไปผิดทิศ (ถ้าผิดกด LT + B ทันที)
  • T2 = gains match: FixStand และไม่มี MISMATCH
  • ค้างนิ่ง 30 s: ห่างจาก qs < 0.05 rad, ไม่สั่น (ดูแขน), อุณหภูมิขึ้นไม่เกิน 5 °C (T1)
  • ดันออก 0.1–0.2 rad ค้าง 1 s แล้วปล่อย ทีละกลุ่ม (เน้น hip yaw, waist yaw, wrist roll): ต้องกลับเข้าท่านุ่มๆ ไม่แกว่ง
  • (ไม่บังคับ) กด Ctrl-C ที่ T3 ระหว่างค้างท่า แล้วจดอาการมอเตอร์: → รัน T3 ใหม่
  • รีโมต LT + B → Passive · หยุด T1 และ T2 ด้วย Ctrl-C (ไฟล์ CSV ถูกบันทึกแล้ว)

  • LT + ↑ FixStand ตอนยังแขวน → หย่อนจนเท้าแตะพื้นเต็มเท้า เชือกหย่อนพอให้หุ่นรับน้ำหนักเอง แต่ยังกันล้มได้
  • RT + A → Velocity (soft start 0.5 s): T2 = gains match: Velocity · slot 13/14/20/21/27/28 ได้ kp = 0 · ไม่มี MISMATCH
  • ยืนเฉยๆ 30 s: นิ่ง ไม่ย่ำ เอียง < 5° (T1)
  • stick ซ้ายดันไปหน้า ~20% (≈ 0.2 m/s) 3–5 s แล้วปล่อย → ถ้าผ่านเพิ่มเป็น ~40% (≈ 0.4 m/s) สั้นๆ (P3b เลี้ยวขวาเอง ~2°/s แก้ด้วย stick ขวา)
  • ถอยหลัง ~20% · หมุนด้วย stick ขวา ~30% ทั้งสองทิศ · เดินด้านข้างด้วย stick ซ้ายแกนนอน ~30%
  • จบ: ให้เชือกรับน้ำหนักก่อน แล้วค่อยกด LT + B (Passive = kp 0 หุ่นจะทรุด)

จอยรีโมตส่งค่าตรงไม่มีการ smooth ให้ดันช้าๆ · ห้ามกด RT + A ตอนหุ่นยังแขวน

หยุดทันที (LT + B) เมื่อ joint ไปผิดทิศ / สั่นถี่ / มีเสียงเกียร์ผิดปกติ · T2 ขึ้น MISMATCH หรือ unknown · T1 ขึ้น STALE / gap > 100 ms / OUT · อุณหภูมิมอเตอร์ > 70 °C · ลำตัวเอียง > 15° · มีคนพูด "หยุด"
ระบบตัดเองเมื่อ: LowState ขาด 100 ms หรือเอียง > 49° (ช้าเกินกว่าจะกันล้ม ห้ามรอให้ระบบตัดเอง)
